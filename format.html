상품 데이터 제출 형식

공급해 주시는 상품 정보를 아래 형식으로 보내주시면 카탈로그에 자동으로 반영됩니다. 항목 이름과 단위만 맞춰주시면 되고, 파일 형식은 편하신 쪽(표 붙여넣기 · TSV · JSON) 아무거나 괜찮습니다.

📊 상품 시세판 보기 📋 상품 등록 폼 열기 🗂 예시 JSON 원본

01 항목 정의

필수 표시된 3개만 있으면 등록은 가능합니다. 나머지는 비어 있으면 화면에서 해당 줄이 자동으로 숨겨집니다.

항목필드명형식예시
창고명 필수warehouse문자동해
상품명 필수name문자임금님 5-6미 전복 1kg
공급가 필수supplyPrice숫자 (원, 쉼표 없이)25500
카테고리 선택category문자수산 / 축산 / 간편식 / 생활용품 …
규격 · 스펙 선택spec문자 배열["1kg / 5-6미", "손질 후 600g"]
기존가 선택previousPrice숫자 또는 null23000 → 인상·인하 자동 표시
면세 / 과세 선택tax문자면세
택배사 선택courier문자씨제이대한통운
택배비 선택shipFee숫자 (0 = 무료배송)4000
발주마감 선택orderCutoff문자당일 14시
유통기한 선택shelfLife문자냉동 12개월
사진 선택image접근 가능한 URLhttps://.../전복.jpg
실제 출고 창고 선택sourceWarehouse문자한 분류에 여러 창고 상품이 섞일 때만 — 상품별 배지로 표시
비고 선택note문자산지직송
🚚 택배비는 창고 단위로 봅니다. 합포장(합배송)이 같은 창고 상품끼리만 가능하기 때문에, 상품마다 창고명을 정확히 적어주시는 것이 가장 중요합니다.

02 보내주시는 방법

셋 중 편하신 방법 하나만 쓰시면 됩니다. 어느 쪽이든 결과는 같습니다.

1
등록 폼 사용 (가장 쉬움) 상품 등록 폼에서 상품을 입력하면 구매자 화면 미리보기가 바로 보이고, 다 넣으신 뒤 표 형식 복사 또는 JSON 파일로 내보내실 수 있습니다.
2
엑셀 · 구글시트 첫 줄에 위 항목 이름을 그대로 쓰고 아래로 상품을 채워주세요. 시트 링크를 보내주셔도 되고, 표를 복사해 카카오톡으로 붙여넣어 주셔도 됩니다.
3
JSON 직접 전달 시스템이 있는 업체라면 아래 형식으로 바로 주시면 됩니다. 사진은 파일을 따로 보내주시거나 접근 가능한 URL을 적어주세요.

03 JSON 예시

이 사이트가 실제로 읽고 있는 파일과 같은 형식입니다 — data/products.json

{
 "updatedAt": "2026-08-08",
 "supplier": "마스터 유통",
 "products": [
  {
   "warehouse": "완전",
   "category": "수산",
   "name": "임금님 5-6미 전복 1kg",
   "spec": ["1kg / 5-6미"],
   "supplyPrice": 25500,
   "previousPrice": null,
   "tax": "면세",
   "courier": "로젠택배/우체국택배",
   "shipFee": 0,
   "orderCutoff": "당일 15시",
   "shelfLife": "냉동 12개월",
   "image": "https://example.com/전복.jpg",
   "note": ""
  }
 ]
}
💡 가격이 바뀐 상품은 previousPrice에 이전 가격을 넣어주세요. 시세판에서 ▲인상 / ▼인하가 금액·퍼센트와 함께 자동 표시됩니다.
